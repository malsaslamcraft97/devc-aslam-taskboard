## Built with

- [React 18](https://reactjs.org/) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com/)

- [NestJS](https://nestjs.com/)

- [Playwright](https://playwright.dev/) — end-to-end tests

## Features

Task management board built as a submission to [DevChallenges](https://devchallenges.io/challenges-dashboard).

- Create, update, and delete tasks
- Categorize tasks by status: **Todo**, **In Progress**, **Done**
- Responsive layout for desktop, tablet, and mobile

## Getting Started

### Prerequisites

- Node.js >= 20
- npm >= 10

### Installation

```bash
npm install
```

### Development

```bash
npm run dev          # starts web on :3000 and api on :4000
```

### Testing

```bash
npm test             # unit + integration tests via Vitest
npm run test:e2e     # end-to-end tests via Playwright
```

### Build

```bash
npm run build        # production build for all apps
```
